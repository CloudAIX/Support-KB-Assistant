# Data and Privacy

## Where data is stored
Customer data is stored in the customer's chosen region. The region is set
when the account is created and cannot be changed afterward without a data
migration request.

## Delete an account
An account owner can request deletion under Settings, then Account. Deletion
removes all data after a 30-day grace period. During the grace period the
account can be restored.

## Exporting data
Any user can export their own data as a file from Settings, then Export. Large
exports are emailed as a download link when they are ready.
